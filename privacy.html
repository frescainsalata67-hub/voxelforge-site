Informazioni sulla privacy

Ultimo aggiornamento: 17 ottobre 2026.

Ambito

Questa pagina descrive l'integrazione Pinterest nella versione locale di VoxelForge esaminata. L'applicazione è destinata all'uso personale sul computer dell'utilizzatore.

Responsabile e contatti

Andrea Montesanti — andreamontesanti00@gmail.com.

Informazioni utilizzate

Il token di accesso Pinterest viene salvato in chiaro nel file locale config/impostazioni.json e trasmesso a Pinterest per autorizzare le richieste API. L'app legge identificativi, nomi, visibilità e numero di Pin delle bacheche; per i Pin legge identificativi, immagini, titoli, descrizioni e collegamenti.

Finalità

Consultare le bacheche autorizzate e scaricare riferimenti visivi selezionati per ricerca creativa, confronto di stile e ricostruzione di oggetti e scene 3D. L'integrazione Pinterest esaminata effettua richieste di lettura e non pubblica o modifica contenuti sull'account.

Conservazione e collegamenti esterni

Le immagini e le relative note sono salvate in dati/riferimenti/pinterest sul computer. Le richieste raggiungono Pinterest e i suoi servizi di immagini. L'eventuale analisi dei riferimenti utilizza i componenti di elaborazione configurati nell'app; la configurazione predefinita indica un servizio Ollama locale. Eventuali servizi remoti configurati dall'utilizzatore richiedono una valutazione separata.

Durata e cancellazione

I file locali restano disponibili fino alla loro rimozione manuale; il codice esaminato non prevede una scadenza automatica. Per rimuovere il token, chiudere l'app e cancellare il valore pinterest_token dal file delle impostazioni. Per eliminare i riferimenti scaricati, rimuovere le relative cartelle locali. Questa operazione non elimina automaticamente eventuali elaborazioni o modelli derivati, che devono essere rimossi separatamente. Le autorizzazioni possono inoltre essere gestite dall'account Pinterest.

Sito di presentazione e hosting

Queste pagine statiche sono ospitate tramite GitHub Pages, servizio di GitHub. Il progetto non include moduli, pubblicità, strumenti di analisi o script di tracciamento. GitHub dichiara di registrare e conservare l'indirizzo IP dei visitatori per finalità di sicurezza, anche quando non hanno effettuato l'accesso a GitHub. Per informazioni sul trattamento dei dati tecnici da parte del fornitore, consultare la GitHub General Privacy Statement. Il collegamento Pinterest si configura nell'applicazione locale e non attraverso queste pagine.
